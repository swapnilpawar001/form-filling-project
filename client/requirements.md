## Packages
xlsx | Parsing Excel/CSV files on the frontend before job submission
framer-motion | For smooth animations and page transitions
lucide-react | Icons for the UI

## Notes
- The app uses a dashboard layout.
- `xlsx` is used in the browser to parse uploaded files into JSON for the bulk job creation API.
- Dashboard will poll or refresh data to show progress.
- Styling uses Tailwind with a custom "premium" color palette.
